## What Is Eter Niu AI Native Social Commerce?

Eter Niu AI Native Social Commerce is a web-focused ecommerce system for B2B and social selling environments. It combines storefront routing, commerce administration, CRM followup operations, and catalog exports for external channels, giving teams one organized foundation for handling sales from multiple customer entry points.

Its commerce layer is based on Medusa and is expanded with OpenClaw seller tooling, WhatsApp followup workflows, Meta catalog feed creation, and PayPhone API Link support. The platform is intended for teams that connect public storefronts to host-based routing while managing customer, order, and event information within the same system.

## Core Capabilities

- Route multiple commerce segments through separate storefront experiences
- Operate a Medusa commerce backend with administration tools
- Use OpenClaw seller utilities and MCP endpoints for connected workflows

- Create Meta catalog exports and feeds for external channel use
- Support payment-related flows through PayPhone API Link
- Keep customer, order, and event operations together in one platform
- Deliver public storefronts that respond to configured hosts and domains

## Working With the Platform

The main operating flow combines commerce administration, storefront traffic routing, and channel synchronization:

1. Create host-based mappings for the public storefronts you want to serve.
2. Manage products, customers, orders, and events through the Medusa administration layer.
3. Run OpenClaw seller tools for tasks that depend on MCP-connected workflows.
4. Configure WhatsApp CRM followups for customer contact and post-order engagement.
5. Generate Meta catalog feeds when products need to be published to Meta channels.
6. Add PayPhone API Link to workflows that require payment handling.

For B2B and social commerce teams, Eter Niu acts as the coordinating layer between store administration, customer communication, and distribution across sales channels.

## Configuration

Configuration generally covers host-based storefront behavior, commerce services, CRM channels, and external integrations. When the deployment uses environment variables, place the values in the application's runtime configuration or `.env` file.

Example:

```env
STORE_ROUTING=host-based
COMMERCE_BACKEND=medusa
CRM_CHANNEL=whatsapp
CATALOG_EXPORT=meta
PAYMENT_PROVIDER=payphone
```

Update these settings for the services, storefront domains, and deployment environment connected to your installation.
